# 📸 Adasa (عدسة) - Photography World Blog

A modern, responsive blog application built with Angular and Tailwind CSS, dedicated to the art of photography. This project demonstrates advanced layout techniques, dynamic view toggles, and rich UI design.

## ✨ Features

- **Modern UI/UX**: Stunning dark mode design with vibrant orange accents, blur effects, and glassmorphism.
- **RTL Support**: Full Right-to-Left layout designed specifically for Arabic content.
- **Dynamic View Toggle**: Users can seamlessly switch between **Grid** and **List** views on the blog page.
- **Detailed Article Pages**: Beautiful, static article layouts featuring sticky table of contents, quick info stats, social sharing, and immersive hero images.
- **Responsive Design**: Flawless experience across all devices (Desktop, Tablet, Mobile).

## 🚀 Technologies Used

- **Framework**: [Angular](https://angular.dev/) 
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: FontAwesome

## 📂 Project Structure

- `/src/app/home` - The landing page featuring highlighted articles.
- `/src/app/blog` - The main blog listing page with the Grid/List layout toggle.
- `/src/app/article` - The detailed article template (currently showcasing the "Golden Hour Photography" post).
- `/src/app/page404` - A custom 404 Not Found page.

## 🛠️ Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) and [Angular CLI](https://github.com/angular/angular-cli) installed.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Dakhlala/angular-blog.git
   ```
2. Navigate into the directory:
   ```bash
   cd blog
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development Server

Run the following command to start the local development server:
```bash
ng serve
```
Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.
